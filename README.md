# BLACKOUT PROTOCOL

Browser tactical shooter. Six operations in Port Vesper: a night raid, a neon heist, a moving convoy, a hostage extract, a bomb defuse, and a last-stand horde. Original game — not affiliated with Valve, Riot, or Activision.

## Play

```bash
npm install
npm run dev
```

Open the local URL. Click **Quick play** or pick a mission from **Campaign**.

## Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look |
| Left click | Fire |
| Right click | Aim |
| R | Reload |
| Shift | Sprint |
| Ctrl / C | Crouch |
| Space | Jump |
| E | Interact / escort |
| G | Grenade |
| F | Flashlight |
| V | Knife |
| 1 / 2 / 3 | Primary / sidearm / knife |
| Tab | (minimap is always on) |
| Esc | Pause |
| Arrows | Look, if the mouse cannot lock |

Counter-strafe: tap the opposite direction to stop and tighten the first shot. Crouch behind crates, stand to shoot over them. Headshots matter. Red barrels chain-react.

## Operators

- **RAVEN** — faster move and swap
- **GHOST** — quieter, later detection, wider radar
- **IRON** — starts armored, resists blasts
- **HAWK** — less recoil, faster aim, harder headshots

Progress, stars, and settings are stored in the browser.
